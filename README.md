# DreamCart Marketplace Backend 🛒☁️

DreamCart is a modern, fast, and asynchronous RESTful API for an e-commerce marketplace platform. Built with Python and FastAPI, it supports multiple user roles (Customers, Salesmen, Admins), dynamic product catalogs using the EAV (Entity-Attribute-Value) model, and secure JWT-based authentication.

## 🚀 Technologies Used

- **Framework:** [FastAPI](https://fastapi.tiangolo.com/)
- **Database:** PostgreSQL
- **ORM:** [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (Async Engine)
- **Migrations:** Alembic
- **Authentication:** JWT (Access & Refresh tokens), Bcrypt hashing
- **Data Validation:** Pydantic V2

## ✨ Key Features

- **Role-Based Access Control (RBAC):** Distinct workflows and access levels for `customer` and `salesman`.
- **Advanced Product Catalog:** 
  - Dynamic product attributes using the EAV architectural pattern.
  - Parent products with multiple variants (color, size, material, etc.).
  - Complex dynamic filtering and SQL joins via SQLAlchemy aliases.
- **Secure Authentication:** Passwords are encrypted using `bcrypt`, and sessions are managed securely with short-lived access tokens and long-lived refresh tokens.
- **Cart & Order Management:** Logic for handling inventory stocks, cart additions, and order tracking.
- **Fully Asynchronous:** Built entirely on asynchronous Python (`async`/`await`, `asyncpg`) for maximum performance and throughput.

⚙️ Installation & Setup
Prerequisites
Python 3.10+
PostgreSQL server running locally or remotely
1. Clone the repository
bash


git clone https://github.com/yourusername/DreamCart.git
cd DreamCart
2. Create and activate a virtual environment
bash


python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
3. Install dependencies
bash


pip install -r requirements.txt
4. Setup Environment Variables
Create a .env file in the root directory based on your configuration:

env


DATABASE_URL=postgresql://user:password@localhost:5432/dreamcart_db
DATABASE_URL_ENGINE=postgresql+asyncpg://user:password@localhost:5432/dreamcart_db
ACCESS_TOKEN_TIME=30
REFRESH_TOKEN_TIME=7
ALGORITHM_FOR_JWT=HS256
SECRET_KEY_FOR_JWT=your_super_secret_key_here
5. Run Database Migrations (if Alembic is configured)
bash


alembic upgrade head
6. Start the Server
bash


uvicorn backend.app.main:app --reload
The API will be available at: http://127.0.0.1:8000

📚 API Documentation
Once the server is running, you can explore the interactive API documentation automatically generated by FastAPI:
